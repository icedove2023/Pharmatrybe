# Decision Trace Schema

Version: 1.0

---

# Purpose

The Decision Trace is an internal audit object that records every step
taken by PharmaTrybe while producing a recommendation.

Unlike the clinician explanation, this object stores the complete
machine-readable reasoning path.

It exists to provide:

- reproducibility
- explainability
- auditability
- regulatory transparency
- research validation

This schema is never edited manually.

Every recommendation generated by PharmaTrybe automatically produces one
Decision Trace.

---

# Ownership

Produced by:

- Decision Engine

Consumes:

- SOAR Output
- ARMD Output (when applicable)
- WHO Knowledge Engine

Used by:

- Explainability Engine
- Audit Logs
- Research Validation
- Future Model Monitoring

---

# Decision Trace Structure

| Field | Type | Required | Description |
|---------|------|----------|-------------|
| trace_id | UUID | Yes | Unique trace identifier |
| request_id | UUID | Yes | Clinical request identifier |
| generated_at | Timestamp | Yes | Generation timestamp |
| scenario | Enum | Yes | Respiratory or Hospital |
| model_versions | Object | Yes | Versions of every model used |
| inputs_used | Object | Yes | Clinical inputs supplied |
| soar_output | Object | Conditional | SOAR prediction summary |
| armd_output | Object | Conditional | ARMD prediction summary |
| who_output | Object | Yes | WHO guideline summary |
| decision_logic | Array | Yes | Ordered reasoning steps |
| final_recommendation | Object | Yes | Final recommendation package |
| rejected_options | Array | Optional | Alternatives rejected |
| explanation_reference | UUID | Yes | Linked Explainability object |
| audit_hash | String | Yes | Integrity checksum |

# Decision Logic

Ordered reasoning chain.

Example

```json
[
  "Patient classified as Community Acquired Pneumonia.",
  "SOAR predicts high resistance to Amoxicillin.",
  "ARMD identifies previous beta-lactam exposure.",
  "WHO recommends Access group when susceptible.",
  "Alternative Access agent selected."
]
```

This sequence is immutable.

# Audit Hash

Every trace produces a SHA-256 checksum.

Purpose:

- detect tampering
- ensure reproducibility
- support publication
- future regulatory compliance

---

# Design Principles

The Decision Trace:

- never contains natural-language explanations
- never replaces Explainability Engine output
- records every reasoning step
- allows complete replay of recommendations
- links all engines together

---

# PharmaTrybe Principle

Every recommendation must be reproducible.

No recommendation may exist without a Decision Trace.

This schema forms the permanent audit backbone of PharmaTrybe.
