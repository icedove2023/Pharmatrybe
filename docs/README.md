\# PharmaTrybe



Explainable AI Clinical Decision Support Platform for Antimicrobial Stewardship.



\## Engines

\- Primary AI: SOAR/GSK Respiratory Stewardship Model

\- Secondary AI: ARMD Hospital Resistance Prediction Model

\- Shared knowledge: WHO AWaRe Knowledge Base



\## Stack

\- `apps/web` — Next.js 15 frontend

\- `apps/api` — FastAPI backend

\- `services/\*` — Python AI / knowledge / decision / explainability services

\- `supabase` — Database, auth, and migrations

\- `infra` — Docker and future deployment assets



Application code is intentionally not present yet; this repository currently defines structure only.
